# Barbara Mu — personal website

Plain HTML/CSS, no build step.

## Files
- `index.html` — About, research interests, current and past projects
- `publications.html` — Manuscripts, presentations, other outputs
- `cv.html` — Web CV with a Download PDF button
- `style.css` — All styling; colors are the variables at the top
- `assets/` — Put `photo.jpg` and `Barbara_Mu_CV.pdf` here

## To do before publishing
1. Replace `YOUR-GITHUB` and `YOUR-LINKEDIN` in `index.html`.
2. Add `assets/Barbara_Mu_CV.pdf` (export from Word).
3. Optionally add `assets/photo.jpg` and uncomment the `<img>` in `index.html`.

## Publish on GitHub Pages
1. Create a repo named `<username>.github.io` (or any name).
2. Push these files to the `main` branch.
3. Repo Settings → Pages → Source: Deploy from branch, `main`, `/ (root)`.
4. Site appears at `https://<username>.github.io/` (or `/<repo>/`).
