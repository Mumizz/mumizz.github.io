# Barbara Mu — personal website

Plain HTML/CSS, no build step. Live at https://mumizz.github.io/ (GitHub Pages, `main` branch, root).

## Files
- `index.html` — About, research interests, current and past projects, contact
- `publications.html` — Manuscripts, presentations, other outputs, reviewing
- `cv.html` — Short page with sidebar and a Download PDF button; the PDF is the only full CV
- `style.css` — All styling; colors are the variables at the top
- `assets/photo.jpg`, `assets/Barbara_Mu_CV.pdf`
- `sitemap.xml`, `robots.txt`, Google/IndexNow verification files
